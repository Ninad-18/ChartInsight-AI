# ChartInsight AI

**Transforming Visual Data into Meaningful Insights**

ChartInsight AI is a machine learning-based chart analysis system developed during a virtual internship at **Suvidha Foundation**. The project aims to extract meaningful information from chart images and generate automated insights to simplify data interpretation.

The system analyzes visual representations of data and helps users understand underlying patterns without manually interpreting every chart.

## Features

- **Chart Image Upload:** Supports JPG and PNG chart images.
- **Chart Classification:** Uses machine learning to identify chart patterns and types.
- **Multiple Chart Types:** Supports bar charts, line graphs, and pie charts.
- **Automated Insights:** Generates meaningful textual insights from uploaded charts.
- **Visual Data Interpretation:** Helps users understand trends, distributions, and comparisons.

## Tech Stack

- Python
- Machine Learning
- Scikit-learn
- NumPy
- Pandas
- Matplotlib
- Image Processing

## Project Workflow

1. Upload a chart image.
2. Process the image to extract relevant visual information.
3. Classify the chart pattern using a machine learning model.
4. Analyze the extracted data.
5. Generate meaningful insights based on the chart.

## Supported Chart Types

- Bar Charts
- Line Charts
- Pie Charts

## Project Objective

To simplify visual data interpretation using machine learning by converting chart images into understandable insights, making data analysis more accessible and efficient.
